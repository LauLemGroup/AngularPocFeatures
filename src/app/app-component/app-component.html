🎨 POC SCSS — Fonctionnalités avancées

Démonstration interactive de toutes les fonctionnalités SCSS dans Angular

1 Variables SCSS ($variable)

Les variables SCSS (préfixées par $) sont définies dans _variables.scss et importées via @use './variables' as *. Changer une valeur ici l'applique partout dans le fichier.

  • $color-primary
  • $color-secondary
  • $color-accent
  • $color-warning

2 Mixins @mixin / @include

Un @mixin est un bloc de styles réutilisable et paramétrable, invoqué avec @include. Ici : flex-center(), card() et btn-variant().

Carte via @include card()

Ce bloc utilise le mixin card qui applique border-radius, padding, box-shadow et background en une seule ligne d'@include.

Centré via @include flex-center()

3 Nesting (imbrication)

SCSS permet d'imbriquer les sélecteurs pour refléter la hiérarchie HTML. Le & référence le sélecteur parent. Exemple : .nav { &__item { &--active { } } }

  • Variables
  • Nesting (actif)
  • Media Queries

4 Media Queries @media

En SCSS, les @media s'imbriquent directement dans un sélecteur. Les breakpoints sont centralisés dans _variables.scss et réutilisés via le mixin respond-to($bp). Redimensionnez la fenêtre.

5 Container Queries @container

Contrairement aux @media qui réagissent à la fenêtre, les @container réagissent à la taille du conteneur parent. Redimensionnez le bloc ci-dessous avec la poignée ↘ pour voir l'effet.

6 :host & :host-context

:host cible l'élément hôte Angular (<app-app-component>). :host-context(.dark-theme) applique des styles quand un ancêtre porte la classe .dark-theme. Le bouton en haut bascule le thème.

:host — Styles sur l'élément hôte (display: block, min-height: 100vh…)
:host-context(.dark-theme) — La couleur change quand le thème sombre est actif

7 Interpolation #{}

La syntaxe #{$variable} insère dynamiquement une valeur SCSS dans un nom de sélecteur, de propriété ou une chaîne. Les 4 colonnes sont générées par @each avec interpolation.

  • Col 1
  • Col 2
  • Col 3
  • Col 4

8 Fonctions SCSS @function / sass:color / sass:math

SCSS fournit des modules natifs (sass:color, sass:math) et permet de créer des fonctions via @function / @return. Les blocs utilisent color.adjust(), color.mix() et math.div() calculés à la compilation.

  • color.adjust +25%
  • base
  • color.adjust -20%
  • color.mix()
  • math.div(100%,3)

ℹ️ color.channel($color, "lightness", $space: hsl) remplace color.lightness() déprécié depuis Sass 1.79. math.div() remplace l'opérateur / déprécié.
